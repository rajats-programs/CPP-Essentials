# Rock Paper Scissors

## Description

A console-based Rock Paper Scissors game built using C++ where the user competes against the computer.

The first player to reach 3 points wins the game.

---

## Concepts Used

- Variables
- Conditional Statements
- Loops
- Random Number Generation
- Switch Statements
- User Input/Output

---

## Features

- Computer generates random choices
- User selects Rock, Paper, or Scissors
- Score tracking system
- First-to-3 winning system
- Displays final winner

---

## How It Works

1. User chooses Rock, Paper, or Scissors.
2. Computer randomly selects a choice.
3. The program compares both choices.
4. The winner gets one point.
5. The game continues until one player reaches 3 points.
