# 2.  Number Guessing Game

## Description

A simple number guessing game built using C++ where the user tries to guess a randomly generated number.

The program provides hints to the user whether the guessed number is higher or lower than the actual number.

---

## Concepts Used

- Variables
- Conditional Statements
- Loops
- Random Number Generation
- User Input/Output

---

## Features

- Generates a random number
- Takes user guesses
- Provides higher/lower hints
- Counts number of attempts
- Displays result after correct guess

---

## How It Works

1. The computer generates a random number.
2. The user enters a guess.
3. The program compares the guess with the generated number.
4. The user continues guessing until the correct number is found.
