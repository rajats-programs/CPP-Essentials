# Calculator

## Description

A simple calculator program built using C++ that performs basic arithmetic operations based on user choice.

- Switch Statements
- Variables
- User Input/Output
- Operators

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus operation

---

## How It Works

1. User selects an operation.
2. User enters required numbers.
3. The program performs the selected calculation.
4. The result is displayed.
